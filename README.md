# Muse Guides

Guides for giving [muse.ai](https://muse.ai) superpowers — from your first conversation to a Muse that runs your home and your business.

## The guides

Open any file in a browser to read it.

- **[muse-new-user-guide.html](muse-new-user-guide.html)** — the beginner's guide: start with "just talk to it," then layer on memory, connected accounts, skills, live research, pages Muse builds, schedules and watchers, goals and background agents, voice and calls, side and group chats, and trust controls. Filterable index of all 34 features, a day-by-day first-week plan, and a FAQ.
- **[muse-advanced-guide.html](muse-advanced-guide.html)** — the advanced guide: give Muse a home (always-on PC), Tailscale, a custom Docker server stack, n8n automations, voice and a real phone number, its own email inbox, coding under review, local agents via Ollama, running a business on autopilot, and guardrails. Includes a Muse-at-home vs. DIY comparison, a HyndSyte hosting panel, and an 8-step build order.
- **[muse-step-by-step-guide.html](muse-step-by-step-guide.html)** — the deep dive: 12 steps in build order — selecting the box, the first conversation (intake + house rules), teaching Muse your world, connecting accounts and skills, programming it all in plain English, SSH & keys with hardening and a kill switch, the home server stack (Tailscale, Docker, n8n, Ollama, backups), running websites and apps on HyndSyte with cPanel, databases (SQLite/MySQL/Postgres), Node apps in production, schedules and autopilot, and the advanced finale (local agents, voice, its own business inbox, graduating to a managed HyndSyte VPS). Every step has copyable "Say to Muse" prompts, code blocks, and a checklist.
